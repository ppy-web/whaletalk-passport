连接 WhaleTalk Passport

设备热点无需密码，直接连接。先在电脑的 AI Passport 连接器中点击生成配对码并开启连接，再把显示的电脑 IP 和 4 位配对码填到这里。

选择电脑所在的网络，或能访问这台电脑的同一局域网。
填写 DSH 页面显示的电脑地址。不要填 127.0.0.1、0.0.0.0 或设备自己的 IP。 与电脑显示的数字一致，前面的 0 也需要填写。
高级设置 默认 3101。只有电脑修改了端口时才需要同步修改。

连不上时检查什么？

确认电脑上的连接器显示“正在监听”。电脑需要保持 DSH 运行，并允许 3101 端口通过防火墙。

保存后设备会重启并连接你选择的 Wi-Fi；手机可退出当前热点。设备显示“准备好了”后短按 OK 开麦，DOWN 取消，长按 OK 可返回设置。
